Temporal HandChord

손 동작 전체를 8차원으로 요약하는 기존 codec에, 시간축을 유지하는 16×K latent codec을 추가합니다.

1. 모델 구조

기존 base policy와 raw critic/replay 인터페이스를 유지합니다. 좁은 화면에서는 그림을 좌우로 스크롤할 수 있습니다.

비교 모델손 latentActor 출력비교 목적
Global K88104기존 구조
Temporal K816 × 8224시간축 보존
Temporal K916 × 9240논문의 K9 적용
Global K128128224Temporal K8과 latent scalar 수 일치

2. Hydra에서 실험 전환

Codec 사전학습

codec: global_chunk
codec_targets:
  global_chunk: model.hand_chord.chunk_hand_chord.ChunkHandActionChord
  temporal_chunk: model.hand_chord.temporal_hand_chord.TemporalHandActionChord
model:
  _target_: ${codec_targets.${codec}}
  latent_dim: ${latent_dim}

같은 학습 명령에 아래 override만 추가합니다.

codec=temporal_chunk latent_dim=9

# Global/Temporal K8 × seed 3개 비교
-m codec=global_chunk,temporal_chunk \
   latent_dim=8 seed=42,43,44 \
   train_dataset.split_seed=0

Residual RL

# 기존 ft_hand_chord_residual_flow_unet_img 사용
# 체크포인트 경로만 교체
model.chord_path=/absolute/path/to/run/chord.pt

체크포인트에서 codec 종류와 K를 읽어 actor 출력 크기를 자동으로 결정합니다.

RL 클래스·base checkpoint·action_dim=22·noise_dim=352는 그대로 사용합니다.

3. 구현 순서

  1. Temporal codec 추가model/hand_chord/temporal_hand_chord.py에 TemporalHandActionChord 구현. Encoder의 action 토큰마다 posterior를 만들고, decoder의 latent 반복을 제거합니다.
  2. 공통 인터페이스·로더 연결encode → packed / decode → raw action 계약을 공유합니다. Trainer·best export·RL의 기존 클래스 직접 로딩을 교체하고 v1 global 체크포인트 호환성을 유지합니다.
  3. Hydra selector와 저장 경로 정리기존 pretrain config에 위 selector를 추가합니다. 실행 이름에 codec·K를 기록하고 multirun도 Hydra runtime.output_dir에 설정과 체크포인트를 함께 저장합니다.
  4. 검증 후 동일 조건으로 비교Shape·팔 값 보존·저장/복원·actor gradient를 검사합니다. Raw base, residual이 0인 복원 정책, RL 정책의 성공률을 따로 측정합니다.

실험 조건: 같은 base·데이터 split·seed·학습 예산·KL 정규화를 사용합니다. 첫 비교에서는 시간 차분 loss를 0으로 두고, 이후 별도 실험으로 추가합니다.
